# 引用 / 符号选择弹窗与宿主搜索样式对齐

日期：2026-11-04。状态：自动检查、原生交付和最终集成人工验收通过，按功能分步提交。

## 根因与边界

前次修复解决了 body portal 的字体继承以及 WebKit searchfield 强制控件字体，但搜索框依然缺少宿主的完整表面样式。定向测试在修复前复现：实际输入框为浏览器 `inset` / 2px 边框、0px 圆角，而宿主为 `solid` / 1px、5px 圆角。引用选中行另用 accent-soft，主文字继承普通文本色，路径也没有选中前景色；符号弹窗同样缺少完整选中前景与悬停状态。

把已有宿主搜索框与搜索结果状态移到 shared/controls.css，由真实宿主搜索、引用弹窗、项目符号弹窗共用。统一边框、背景、焦点、占位符、光标、输入文字选中、行选中与悬停、路径选中颜色和圆角。保留各功能布局 / 字号、import 过滤、键盘导航和关闭逻辑。文字选中样式只限搜索输入，不影响代码编辑器。没有新增依赖、后台工作、日志或权限。
