## 定位与修复

用户指出底部 Find 引用结果窗口仍显得偏大。实际渲染复现：默认 UI 13px 时，Find 的 code 为 13px，宿主搜索摘要为 11px，字体族相同；Find 专属规则错误覆盖了共用摘要规则。文件名还被额外设为 600 字重，宿主文件树为 400，分组计数固定 11px，行号固定 9px。目录和结果标题本来已随应用字号，不需要整体缩小窗口。

| 内容 | 默认 UI 13px 修复前 | 修复后 / 来源 |
| --- | --- | --- |
| 目录、文件名 | 13px；文件名另加粗 600 | 13px，正常 400；共用 compact tree |
| 命中代码摘要 | 13px | 11px；共用宿主搜索摘要 |
| 分组计数 | 固定 11px | 10px；共用 compact tree count |
| 行号 | 固定 9px | 默认 9px；随 UI -4px，最小 9px |
| 标题、排除 import | 应用字号 | 继续采用应用字号 |

删除局部 code 字号 / 字体覆盖和文件名加粗，将计数接入已有共享类。行号调整作用于原本共用的搜索 / Find 位置标签，两边同步随应用字号变化；没有修改编辑器设置、用户偏好、LSP / 插件或结果读取与导航。
