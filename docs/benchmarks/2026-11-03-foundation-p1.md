# P1 分步实施回执

日期：2026-11-03。上位 [实施表](../engineering/2026-11-03-foundation-p1-execution-plan.md)。自动验证、原生交付及人工验收分别记录。

## O3 工具链身份

已接入无 UI 的 `asterlyn-process::toolchain`：有界只读 JDK 检查、规范化安装位置、release 与 java / javac 内容身份、要求及固定失败类别。Gradle 任务沿用原有显式 / 环境 / 安装选择规则，日志增加构建 JVM 角色、来源、版本和要求，不记录安装路径。打包分析按声明选择最低兼容 JDK，明确区分项目模型工作进程与语言服务器。

语言审查返回可选工具链快照，旧响应继续兼容。授权弹窗与状态详情展示实际 JDK、要求及选择原因，快照不授予执行权限；底层工具资源身份仍绑定批准、模型缓存及运行前复验。增加分析工具原来缺少的 release / java / javac 符号链接包含检查。身份摘要格式升级会使旧运行身份缓存失效，不降低校验。

| 自动验证 | 结果 |
| --- | --- |
| 进程核心 | 5 项：版本 / 要求、位置及内容替换、项目内 / 相对路径、读取上限、符号链接逃逸 |
| Gradle 原有规则 | 7 项全部通过，含显式不兼容拒绝及前后复验 |
| 原生工具解析 | 不同 JVM 要求、最低兼容选择、角色区分、内容替换及缺失；定向工具测试 2 项通过 |
| 前端 | 类型检查、构建、1431 项脚本测试通过 |
| Chromium / WebKit | 工具详情键盘展开、长路径换行、进度 / 恢复 / 选择 / 焦点与清理回归通过 |

资源边界：目录候选沿用每根 128 上限；release 最多 64 KiB、每个 launcher 最多 64 MiB，摘要流式读取使用 64 KiB 缓冲区；未启用服务时不运行后台工具扫描。渲染维持已有 100 次状态更新 / 1500 ms 本地门槛及循环回收检查，不把夹具时间当作真实项目速度。

限制：身份检查不是整套 JDK 库完整性证明；源码目标版本仍由项目模型表达，不从运行 JVM 推导。真实图标启动、boostCleaner 模型 / task 扫描、安装快照及最终原生交付随 P1 收尾补齐；Windows / Linux 待 CI 实际执行。无新增第三方包版本，未升级宿主 / 插件版本或发布远端。

## O4 核心门禁与组件预算

新增三 OS 的独立核心工作流，无 Tauri / GTK / 私有项目依赖。显式 `process-fixtures` 使用 runner 的绝对 Node 路径；未配置时失败，不空返回。覆盖真实 stdio 的 Unicode 未保存同步、取消后旧回复、EOF 与新进程、非法帧；发现并修复 EOF / 协议终止后请求表未立即关闭的问题。

本机核心 40 项、真实进程 3 项通过。真实进程 runner 对输出及时间有界，退出 / 中断只终止自身进程树；完整日志在 `target/core-language-gates`，CI 按 OS 归档。Windows / Linux 工作流尚未在远端运行，不宣称通过。

组件预算由 `protocol/language-experience-budgets.v1.json` 管理，原有导航 CI 已实际执行新断言并归档 JSON。每浏览器 30 次真实修饰键点击：Chromium 反馈帧 p95 7.8 ms、响应到结果帧 p95 15.2 ms；WebKit 分别 17 / 14 ms，均通过 100 / 50 ms 门槛。Chromium 20 轮导航 / 弹窗后的保留堆增量 172,996 字节，低于 2 MiB 门槛。键盘 / 焦点、脏缓冲区、旧结果、512 行选择器与减少动画继续通过。

这是确定性后端的组件测量，帧采用 requestAnimationFrame 时间戳，不是显示器扫描或真实 Android 首查。真实后端首查 1 秒 / 热查 p95 500 ms 仍作为私有探针目标，不能用这些组件数据证明；全 WebView 物理内存也不能从保留 JS 堆推导。完整应用及项目的收尾回执继续独立记录。

## O5 语言应用服务

会话、一次性审查、actor、进度、诊断代际、来源校验、私有缓存与持久批准已迁入现有语言核心 crate。原生代码不再保留第二份 manager，只有 App 目录适配、工作区 / 包 / 工具准入、模型资源桥接和事件投递。模型资源桥接持有原有 lease 的唯一句柄，核心只接触 `ModelResource` 生命周期端口；批准文件名、指纹及事件 / 命令 wire 保持原样。

| 验证 | 结果 |
| --- | --- |
| 无桌面依赖 | `cargo tree -p asterlyn-language-service` 不含 Tauri / GTK |
| 核心门禁 | 50 项通过；旧的缺少环境便空返回的外部探针已移出默认测试集 |
| 可移植传输 | 3 项真实进程测试通过 |
| 应用 actor feature | 32 项通过；runner 额外逐名要求 EOF、取消及内部恢复代际三项实际通过，不能用纯模型测试数替代 |
| 真实 TS | actor 的未保存 / 诊断 / 请求 / 清理，以及独立 transport 的 Unicode / CRLF 测试分别实际通过 |
| 桌面适配 | 原生类型检查、封包准入 / 隔离激活、1431 项前端脚本通过；clippy 拒绝警告通过 |

外部工作区、TypeScript、Rust、Android 的测试分别使用明确 feature，缺少必需输入直接失败；公有 CI 不默认读取私人工作区。第一轮发现了外部 trait 实现的归属约束，改为原生层持有模型 lease 的明确适配器；未迁入 Tauri 或模型提供者实现。迁移复用原有资源边界，不新增进程、后台索引、依赖版本或并行状态库。原生安装与真实 Android 故障回归留待最终构建验收。

## O6 原生模型与结构化故障

语言审查 DTO、工具链快照及固定故障 DTO 以原生 serde 模型为权威，通过可选 `bindings` 生成前端类型与结构校验元数据。命令表 / v1 治理保持原样；`npm run protocol:native:check` 重新运行原生导出并逐字检查漂移，已接入三 OS 核心门禁。整数输入仍要求 JS 安全整数，枚举、camelCase、optional / nullable、数组边界和未来输出字段分别处理，特定身份 / 路径等语义限制继续校验。

旧审查缺少 remembered / toolchains 字段仍可用，旧事件 code 和命令错误字符串保留。终止 / 降级事件新增可选固定 failure：类别、可重试属性、展示信息及可空请求标识；来源 code 不进入自由文本。重试属性不是批准，客户端仍受 P0 的身份与预算约束。状态面板按固定类别本地化，不能展示未经校验的服务器原始消息。

真实原生桥接原有另一套审查校验，已改为使用同一个协议校验入口；纯 wire 解析独立于 Tauri 加载及 window，全路径测试能验证畸形工具链也被拒绝。1435 项脚本测试、原生检查、51 项核心 / 3 项真实传输 / 33 项 actor feature 与绑定漂移检查通过；Chromium / WebKit 的结构化失败展示及工具链详情通过，clippy 拒绝警告通过。启动生成 chunk 门槛维持原值，前端构建通过。

工具来源：复用锁文件中的 schemars 0.8.22（MIT，`GREsau/schemars` 发布 crates.io 包），归档校验 `3fbf2ae1b8bc8e02df939598064d22402220cd5bbcca1c76f7d6a310974d5615`。仅 bindings 编译启用，普通语言核心不启用该特性，没有新增第三方版本。生成类型 1,568 字节、校验元数据约 3.7 KiB（源文件口径，不冒充打包体积）。没有全库 wire 迁移，未知的旧后端结果覆盖仍为 unknown。


## O7 按需语法候选（源码验证）

新增显式命令 `workspace.symbols.open`（Primary+Option/Alt+O），按需加载独立弹窗及插件完整性覆盖的数据规则。TS/JS、Rust、Java/Kotlin 声明由通用有界词法引擎提取，明确标为语法候选；不更改语义 F12 / 引用路径。Android 范围来自当前获准模型资源，使用源模块及其传递依赖；无有效模型时不退回后缀匹配。不增加 SDK、权限、解析器依赖或常驻进程。

缓存使用现有目录事实、源码访问和文件观察身份；已保存名称 / 位置 / 摘要原子持久化，8 MiB/文件、8 文件/32 MiB 总量，50,000 条事实及 LRU 淘汰。每次命中复核内容，打开前复验来源、规则、模型及窗口覆盖。未保存内容仅随请求存在；超限脏文件明确排除，不用磁盘内容冒充。详细边界及语法遗漏见 [ADR-0037](../architecture/decisions/0037-plugin-owned-syntax-candidates.md)。

自动验证：1437 项脚本测试、类型检查、生产构建；原生 173 项通过 / 3 项既有显式忽略；工作区 81 项原有 + 5 项符号集成及后补 1 项缓存淘汰，Git 156 项；新增五语言 / UTF-16、字面量、模型依赖范围、缓存重开 / 增量 / 损坏 / 淘汰、取消、符号链接越界、未保存隔离及完整 512 项协议校验。Clippy 原生及核心 `-D warnings` 通过。三 OS 门禁增加显式符号夹具，本机核心 51、进程 3、actor 33、符号 5 及原生类型漂移检查通过；Windows/Linux 尚待远端实际执行。

Chromium / WebKit 覆盖名称查询、取消、Arrow/Enter/Escape、焦点返回、脏覆盖变更、来源复验、项目切换、20 次打开关闭及清理；Chromium 20 次循环后保留 JS 堆增量 80,968 字节（局部组件口径）。既有状态、真实修饰键定义/引用及 Find 分组树回归通过。此处曾发现 search 输入的 Escape 清空行为和 WebKit 移除 dialog 后无 close 回调的问题，现统一显式关闭和焦点回收。
