# P0 O1：状态、提供者选择与结果覆盖

日期：2026-11-03。源码与自动验证通过；安装态闭环随 O2 单独记录，尚无本轮人工验收。

## 行为与边界

- 原生 ready 附带受限原因时，投影为部分可用；保留后台索引阶段 / 模块进度，不冒充全部失败或全部就绪。
- 多个贡献者覆盖同一语言时显示选择要求；偏好绑定项目 / 语言，使用已准入贡献 ID。选择不代替执行批准。原选择被禁用或卸载后不会静默改用另一个提供者。
- 已选择后仍可在语言状态里改变选择；更换时撤销旧文档绑定、停止无用户的后台 profile，再绑定新项。当前 SDK 的语言功能为同一 bundle，不新增未经协商的分功能元数据。
- 覆盖范围与数量截断分开。标准旧 LSP 数组为 unknown；合法包装可报告 complete / partial / unknown 及固定原因；无效元数据退回 unknown，丢弃无效位置的结果不能继续声明 complete。
- 引用弹窗和 Find 保留相同覆盖元数据；import / 路径过滤及树 / 平铺不改变语义覆盖。空的部分 / 未确认结果不再误报为“确认没有引用”。现有旧包仍可用，不增加 SDK 权限或改变旧包的服务器响应。
