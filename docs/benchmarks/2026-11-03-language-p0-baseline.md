## 测量口径

在用户日常工作的 macOS / Apple Silicon 机器执行，应用未被关闭，也未清理系统 / 用户缓存。
五个场景各三组冷、热进程：30 次启动，每次首查单列，再做 30 次 definition → references，共 900 次热样本。
每次比较规范化 URI / 精确范围的摘要，五个场景均跨六次启动保持同一结果集；源码摘要前后一致，全部测量进程组最终为零。

Android 使用新的专用分析缓存测冷启动，再复用该缓存测热重开；不删除用户 Gradle / 分析缓存。
TS/JS/Rust 每次都是新服务进程，其“冷 / 热”标签只表示配对顺序，不声称它们支持持久语义缓存。
就绪耗时测到固定声明的第一次真实查询完成；`initialize`、后端 ready 和真正语义结果分别记录。
数量限制和覆盖范围分开：旧服务器未声明覆盖范围，因此记录 unknown，结果集一致不等于全项目语义完整。

TS 使用 Asterlyn 的 `editorLanguageDescription`，JS 使用 `hashFile`，Rust 使用 `decode_utf8_text` 声明。
第一次选取的 TS 声明本来没有调用，探针因零引用拒绝作为有效性能样本，随后改为有真实调用的声明；不把空结果耗时当成成功基线。

## 资源所有权与协议影响

| 资源 / 事实 | 唯一所有者 | 恢复边界 |
| --- | --- | --- |
| 文档版本、撤销、未保存正文 | 窗口编辑器；语言客户端同步最新快照 | 不持久化脏文本，不复活已关闭文档 |
| 项目批准、精确工具 / 包身份 | 原生授权管理 | 恢复前重新准备 / 复验；身份变化不能自动批准 |
| 整个语言适配器进程 | 原生 actor + 窗口语言生命周期 | 前端协调重建，所有进程创建仍由原生批准 / 监督 |
| Android 内部 JDT / 模块 Kotlin JVM | Android 适配器 | 插件处理内部失败；宿主不竞争重启同一子进程 |
| AGP 模型与租约 | Android 插件提供事实，原生 actor 持有有效资源 | 新 actor 重取租约，不续用旧代际 |
| 不可变分析缓存 | 经身份校验的分析组件 | 私有会话状态可丢弃，缓存可重建；不清全局依赖 |
| 结果与诊断 | session / URI / version / model generation | 旧代际、旧模型或旧文档回复不能发布 |
| 项目提供者偏好 | 宿主偏好与已准入 registry | 选择不授予权限；未安装的显式选择不能静默回退 |

O1 只扩展宿主投影，标准 LSP 数组保持兼容，覆盖范围默认 unknown；当前 SDK 每个语言 profile 的功能为同一组，不编造分功能能力声明。
O2 不新增进程权限、服务器布局、源码读取或写操作能力；新 SDK / 宿主版本变更另走兼容性治理。

## 故障矩阵与策略

| 触发 | 可自动恢复 | 验证归属 |
| --- | --- | --- |
| 已确认适配器意外 EOF / 启动 EOF | 最多三次，500 / 1000 / 2000 ms | 宿主 O2：实际 actor 进程 + 文档客户端 |
| JDT / Kotlin 内部意外退出 | 同一后台进程的独立三次预算 | 插件 O2：stdio 与真实 Android 故障探针 |
| 稳定 ready 不足 180 秒即再次崩溃 | 不重置预算 | 两侧策略单测与连续崩溃探针 |
| 普通单次查询超时 / 分析中 | 不杀进程，不重放旧导航 | 原有请求隔离回归 + O2 |
| 配置 / 凭证 / 模型 / 缺少工具 | 不定时无限重试 | 插件失败夹具、宿主状态投影 |
| 变更工具 / 包、撤销授权、隔离、主动停止 | 不恢复 | 重新授权、项目切换 / 卸载 / dispose 回归 |
| 协议或资源 / 完整性边界失败 | 不恢复 | framing、actor、组件及插件边界测试 |
| 旧请求、旧诊断、恢复期间编辑 / 关闭 / 切项目 | 丢弃旧结果，只同步仍打开的最新文档 | 客户端代际与进程故障组合测试 |

## 预算与明确限制

- 保留现有进程、输出、文档、CPU / 内存及并发硬边界。恢复不是放宽门槛。
- Android 首次编译 ABI、缓存重开、首查、热查分别衡量；机器正在运行其他工作，方差不能当成稳定 SLA。
- 当前固定查询的 500 ms 热 p95 目标在部分 Android 轮次未达成；P0 不靠减少真实结果掩盖这点，后续 O4 继续优化。
- RSS 是后代进程抽样总和，非物理 footprint；桌面 / WebKit XPC 没有归入直接服务器数字。附带原生运行态观察也不是完整冷启动或全应用物理内存验收。
- 本轮真实测量仅 macOS；不宣称 Windows/Linux 通过。UI 帧、焦点 / 无障碍、整应用启动与安装验收在 O1/O2 独立记录。
- 探针只保留摘要、数量、时间、阶段和 stderr 字节数，不保存正文、原始 RPC / stderr、引用 URI 或环境值。
