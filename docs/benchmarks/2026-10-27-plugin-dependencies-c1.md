# 插件强依赖 C1 验收

日期：2026-10-27。计划及边界见 ADR-0035 和插件构建模型协作计划。

## 已实现

- SDK 1.13.0 的静态 dependencies 声明与 pluginDependencies capability；旧宿主不接受未知能力。
- 纯 Rust 依赖内核（64 节点、每包 16 条声明），稳定数字版本区间；原生安装协调器在同一事务内启用依赖闭包，拒绝缺失、不可用、不兼容、循环及非法声明。
- 禁用/卸载/切换/修复/准入使用原生约束，启用偏好而非运行状态决定依赖锁。宿主随包维护 requiredDependencies 最低约束，回退到未声明依赖的旧 LSP 包也不能解除用户指定的关系。
- LSP 0.2.1 真实包依赖 Android Gradle >=0.5.10、<1.0.0。关闭 LSP 释放其锁，Android 保持启用；其他消费者继续锁定。
- 安装变更全窗口通知，健康的其他插件不重启；管理页开关/卸载显示可访问的禁用原因。启动和回调均检查依赖可用性。
- 关闭 LSP 撤销当前授权代次、清理会话，消费过但尚未完成的旧启动不能在快速重新启用后复活。恢复过程中允许依次关闭故障消费者，不因其他消费者仍不可用而形成无法关闭的死锁。

## 范围与限制

C1 完成启用关系和执行门禁，不代表 C2–C4 的 Android 模型提取/服务器适配已完成，也不改变既有 Android/JVM A0 语义失败结论。
