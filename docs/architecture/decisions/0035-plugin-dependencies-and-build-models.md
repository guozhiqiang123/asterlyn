# ADR-0035：插件强依赖与构建模型协作

状态：2026-10-27 接受实施。执行计划见 [插件协作计划](../../engineering/2026-10-27-plugin-build-model-cooperation-plan.md)。

用户明确要求 LSP 启用期间 Android Gradle 插件不可关闭；关闭 LSP 后才可解除该依赖锁。
此关系为静态插件强依赖，不以当前项目语言、是否运行语言服务或 provider 是否激活为判断条件。

宿主负责通用依赖闭包、兼容性、原子启用与禁用/卸载/版本切换门禁，以及插件准入、执行、制品和编辑器边界。
Android 插件负责 Android/Gradle 模型及适配，LSP 插件负责后端及模型消费。此决策修订 ADR-0034 后续计划中将
Gradle 导入和 Android 模型业务集中在宿主的描述，保留其进程监督、权限和文档一致性要求。

依赖可促成兼容已安装插件的启用，不授予执行权限，不自动下载缺失包。依赖图在原生管理层权威校验，UI 仅投影；
兼容性和依赖约束同样覆盖升级、回滚和卸载。插件崩溃不改变用户启用偏好，也不能使仍被启用的依赖者失去保护。

模型服务是单独的版本化能力；Android 插件作为生产者，LSP 作为消费者，宿主协调工作及只读制品引用。大模型和
长时 JVM/Gradle 工作走受监督附属程序通道；隔离 JS 回调只传有界控制数据。缓存、访问和结果均与插件/工作区/
构建根/选择意图/模型 generation 绑定。模型字段不能扩大文件或进程权限。

启用 Android 插件本身不启动模型工作；打开相应语言文档并需要语义时才按需请求。运行配置选择作为分析意图，
AGP 模型确认实际变体关系。Java/Kotlin 的后端模型消费、分发及混合未保存内容各自验收，不由依赖启用推定成功。
