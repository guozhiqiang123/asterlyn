# ADR-0037: On-demand syntax candidates from plugin data

Status: implemented; native P1 delivery evidence is recorded separately.

The language plugin may ship `servers/symbol-index.v1.json` as an integrity-covered, bounded data resource. The current first-party provider uses schema 1 / `tokens-v1`. No executable rule, regex program, parser dependency, new process, SDK capability or permission is added. An older host ignores the resource; a missing resource is unsupported, never a semantic fallback. Keywords, lexical delimiters and generic model projection pointers belong to the language plugin.

`asterlyn-workspace::symbols` owns a generic bounded lexer and derived saved-file cache. The native adapter obtains the active window's authoritative non-ignored catalog and admits exact selected package bytes. It does not walk another file tree. Explicit **Find Project Symbols** / Primary+Option/Alt+O loads the presentation lazily; closing releases requests, timers, DOM and buffers. Results say **syntax candidates**, support Arrow/Enter/Escape and return focus. F12 and references remain semantic operations.

Java/Kotlin profiles require the approved active `android-jvm` session's model lease. A generic projection reads only a sealed current artifact and produces module IDs, roots and dependency edges. With an active source origin, the longest owning root and its transitive declared dependencies restrict the catalog; no origin admits all model roots. Unmatched, absent, stale or unauthorized model scopes do not expand to suffix matching. No Gradle rerun is started by this operation. Projection graphs remain owned by the model resource and disappear on invalidation. Saved syntax facts can be shared across model generations; each result still binds and rechecks the current scope token.

Saved facts bind canonical root identity, source observation/revision, plugin content/rules, schema and engine. The cache contains names, positions and hashes, never source text; private atomic files are limited to 8 MiB each, 8 files / 32 MiB total. High-resolution Unix change observations may reuse negative facts; platforms without that assurance re-read content. Every positive rechecks content, and selection re-extracts the selected declaration. Corrupt/obsolete files rebuild, oldest derived facts are evicted, and no diagnostic export includes this cache.

Dirty overlays are request-local, capped at 128 entries / 8 MiB; oversized dirty buffers use an explicit exclusion marker, never disk fallback. No overlay is persisted. Selection compares current window overlays before and after native source/model validation and uses the existing editor navigator/history. Workspace, plugin, model or buffer changes discard stale responses.

Per request: 256 KiB/source, 512 declarations/source, 50,000 cached facts, 5,000 inspected source files, two seconds of source work, 512 results. Catalog limits remain authoritative. Partial/budget/unsupported scopes are explicit, not complete indexing claims. The lexer is deliberately conservative: templates, macros, complex declarations, Rust raw identifiers and uncommon grammar can be omitted; it is not an AST or compiler and cannot resolve overloads, types or references. Unicode positions use UTF-16. Tests cover TypeScript/JavaScript, Rust, Java/Kotlin data rules, comments/literals, model closure, cache invalidation/corruption/eviction, unsaved isolation, cancellation and rendered lifecycle. Private project probes are explicit inputs, not CI prerequisites or semantic performance claims.
