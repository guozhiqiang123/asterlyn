## 实施顺序

| 步骤 | 本次闭环 | 验证与退出标准 |
| --- | --- | --- |
| O3 | 在无 UI 的进程核心统一有界 JDK 身份检查与角色快照；Gradle 继续沿用已验收选择优先级；打包分析工具保留声明要求及确定性选择 | 空 / 不兼容 / 显式配置、同版本不同位置、替换、符号链接越界与读取上限；语言授权及状态可解释各 JVM；工具变化使原批准 / 模型缓存失效 |
| O4 | 接入轻量跨平台核心生命周期 / 协议门禁及可重复体验预算；大型私有 Android 测量保持显式探针 | 本机完整执行，CI 矩阵不静默跳过必需夹具；Windows / Linux 未实际运行时明确标记待 CI，不能从配置推导通过 |
| O5 | 迁出语言生命周期中的第一片完整服务，注入事件 / 缓存 / 模型端口，保留桌面授权与原生目录适配 | 核心不依赖 Tauri，可无桌面运行真实进程夹具；没有双份会话 / 审批状态，窗口隔离和退出回收不变 |
| O6 | 以原生语言模型为权威建立一条类型生成、运行时校验、漂移检查闭环，增加稳定错误分类 | camelCase、枚举、optional / nullable、未知字段及 JS 安全整数；既有命令版本和旧响应兼容 |
| O7 | 打通显式、按需的项目符号候选查询；提取留在语言插件，宿主只管理身份 / 派生缓存 / 窗口覆盖与展示 | 已保存缓存、重开 / 增量 / 损坏 / 淘汰、未保存隔离；结果明确标记语法候选，不能替代语义引用或绕过 Android 模块图 |

O7 先验证 TS/JS、Rust，再在真实 Android 模型许可的来源范围扩展 Java/Kotlin。未完成对应语言的实证不能宣称兼容。新增进程、解析器或 SDK 能力需单独记录来源、包体、授权与旧包退化；不默认安装工具、扫描所有项目或启用全量索引。

## O3 冻结边界

- `crates/asterlyn-process`：通用工具链数据与文件检查，不决定 Gradle / Android 兼容规则，也不执行发现的程序。
- `src-tauri/src/application/{java_installations,gradle_task_runtime}.rs`：平台发现和既有 Gradle 策略。显式不兼容选择继续报错，不擅自改用另一 JDK。
- `src-tauri/src/commands/packaged_analysis/tools.rs`：插件声明要求与核心 JDK 检查连接。分别表达分析 JVM 和构建 JVM，源码目标版本仍由模型表达。
- 语言协议、授权展示和状态面板：有界只读快照，标明角色、版本、位置、身份、要求和选择原因。快照不授予执行权限，批准仍绑定原有精确包 / 工具身份。
- 身份检查覆盖规范化 home、release、java / javac 内容；不声称校验整个 JDK 所有库文件。保留现有运行前复验和受限环境，不全量继承 shell 环境。

## 提交与交付

每片先定向验证再提交；完整门禁及真实客户端验收单独收尾。仅本地提交，不升级宿主版本，不推送或发布。真实项目以日志证据为主，UI 只验交互终点；保留用户 `.openidea/` 等既有文件。产品修复完成后按本地构建规范重新签名、覆盖安装并验证两次图标书签重开。

每片记录功能、耗时、资源口径、键盘 / 无障碍、兼容性和已知限制。CI 配置完成、源码测试、封包验证、原生安装和用户人工验收分别记录。

执行记录：O3 源码与自动验证已完成，详见 [P1 回执](../benchmarks/2026-11-03-foundation-p1.md)。原生集成和安装在最终产品构建中验收，尚未标记整个 P1 完成。

O4 已提交 `0f58921`，本机核心 / 真实进程及组件预算通过；远端 OS 验收仍待执行。O5 经调用链复核选择完整语言应用服务作为首片：会话 / 审查唯一拥有者、actor、诊断、进度、来源校验、私有缓存和项目批准迁入现有语言核心 crate。原生层保留 App 数据目录、工作区准入、包 / 工具复验、模型代理及事件投递；通过已有身份、受限 profile、模型生命周期回调、事件回调和宿主提供的缓存路径连接，不新增会话镜像或仅转发的壳。真实服务器夹具改为显式 feature 与必需输入，不能静默空返回。

O5 已提交 `0ebb31f`。O6 选择语言审查结果 / JDK 快照和固定故障信息作为首个生成闭环：复用锁文件中已有的 schemars 0.8.22，仅在 `bindings` 特性编译时生成 schema，正常客户端不启用；原生 serde 模型生成前端类型 / 结构校验元数据及漂移检查。旧审查响应缺少可选字段继续兼容，原命令错误字符串及事件 code 保留；新增可选故障对象只输出固定类别 / 重试属性 / 展示信息。同步消除原生桥接审查校验与公共协议校验的重复，确保真实调用路径也校验工具链快照。

## O7 实施边界

O6 已提交 `a35b929`。符号首片采用插件内完整性保护的 `servers/symbol-index.v1.json` 纯数据规则，供有界通用词法提取器读取；关键词、注释 / 字符串方式、声明规则及模型投影均在语言插件，不在宿主按语言硬编码。不引入解析器依赖、可执行规则或新的常驻进程。首版是保守的语法候选，明确标注，不能替代 F12 / 引用的语义结果；不承诺完整 AST / 编译器级提取。

- 宿主工作区核心复用现有文件读取、目录事实及文件观察身份；只持久保存已保存源码的派生名称 / 位置，绑定根目录、内容、规则 / 引擎及 schema 身份。损坏重建、容量有界，未保存覆盖仅在窗口请求内，不入持久缓存。
- 首个数据提供者为现有 LSP 插件，规则缺失时正常退化为不支持符号候选，旧宿主忽略新增纯数据文件；不改变 SDK、权限或最低宿主。
- Java/Kotlin 规则声明依赖已批准的 `android-jvm` 项目模型；通过现有模型资源生命周期端口读取有界、受保护的 artifact，再按插件声明的通用字段投影获得模块 / 来源根 / 依赖图。模型失效或服务未启用时不扩展 Android 候选范围；无后缀 / 同名语义回退。
- 独立显式符号入口与快捷键，按需查询，有 loading / 部分范围说明、键盘选择、取消及焦点恢复。来源变化、项目切换、规则 / 模型变化后丢弃旧结果；打开前复验来源 / 覆盖身份，沿用编辑器导航历史。
- TS/JS、Rust、Java/Kotlin 分别用最终封包规则验收；模型隔离、跨模块范围、相似符号、Unicode、关闭期间改动、脏覆盖和缓存替换单独验证。任何语言未通过不能宣称兼容。

O7 源码与离线 / 组件门禁已实现；采用 [ADR-0037](../architecture/decisions/0037-plugin-owned-syntax-candidates.md)。宿主 0.1.25、插件 0.3.13 的最终签名整包与原生验收仍单独收尾，不从自动测试推导完成。
